# ruster

`ruster` は、自宅ラボ向けにフルスクラッチで作るソフトウェアルータプロジェクトです。

狙いは、Linux依存を最小化しつつ、パケット処理の中核を自作して仕組みを完全に理解できることです。将来的には SRv6 uSID などの新しい技術にも拡張できる土台を目指します。

## ビジョン

- データプレーンの挙動を自分で実装し、理解できる状態にする。
- NAT込みで 10GbE 回線を実用できる性能を目指す。
- 将来の機能追加に耐える拡張性を最初から意識する。

## v0.1 のフォーカス

- ターゲットは自宅ラボ。
- 「家庭用ルータとして普通に使える」を最優先。
- L2/L3転送と NAT を最小有効プロダクトとする。

## 設計原則

- パケット処理コアは完全自作。
- 暗号、CLI、補助ツールなど非コア領域は外部依存を許可。
- 標準準拠を優先し、独自プロトコルは原則作らない。
- 暗黙設定は禁止し、挙動は設定と状態から読めるようにする。

## 設定モデル

- 宣言的な基準設定として `router.toml` を持つ。
- 運用上必要なランタイム変更は許可する。
- 適用フローは `validate -> plan -> apply` を必須とする。
- ランタイム変更は差分として保持し、明示操作で `router.toml` に反映する。
- 自動ロールバックは v0.1 では必須ではない。

## 性能目標（v0.1）

- NAT有効時でも 10GbE 回線で実用できること。
- 初期評価は 1500B パケットを基準にする。
- 64B 線速最適化のような厳密性能追求は v0.1 の必須外。

## 将来展望

- OSPF/BGP など動的ルーティング対応。
- SRv6 uSID を含む高度プロトコルへの対応。
- 性能最適化と対応ハードウェアの拡大。
