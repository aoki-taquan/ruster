# Backlog

レビューで出たMedium以下の指摘や、後で検討することを一行ずつ書く。
作業するかどうかはcharterに照らしてownerが決める。

- 待ち受けの前に残ったsocketを消すとき、まだ動いている同じプロセスのsocketも消してしまう（二重起動に気づけない）。先にconnectして確かめる。
- acceptが失敗（開けるファイルの上限など）したとき、黙って次の回に回している。数えるか記録する。
- netnsの試験はpingだけ。TCPとUDPも通すと、チェックサムの扱いまで確かめられる。
- 設定ファイルで、静的経路が直結の範囲と同じprefixだと直結を置き換える。置き換え先のインターフェースが無効でも黙って置き換わる。
